This drupal 7 modules does something every drupal developer wanted since the creation of Drupal 7. It deletes modules from the server without you actually having to go, login to your server and move files manually. 

This module might throw an error and say something "could not be deleted" but in reality it probably was deleted. 

You must be careful using this module as you can figure it will delete files including important ones. For power users that want a clean modules page this is a super useful module. It is like the dust buster of modules it can take all our old uninstalled modules and straight up delete them, without you taking an hour navigating through your server trying to find things. 

Use this module at your own risk. 

Since your deleting modules make sure you know what your deleting, or you could break your website. It is unlikely because it looks for disabled modules and uninstalled modules, but you should delete modules with care, it shows a list of all kinds of things to delete you may not want to. For power users this is a cleaning utility to make your job easier and faster so enjoy it. If your a power user you should know the machine_name and url path for most of what you want gone, so this is awesome for that. 

Note for power users, this might leave a couple files behind time to time, in the case of Ubercart I was able to delete literally 99% of the modules files and all its functionality, and the module vanished from the modules page, but it left like 1 or 2 random files in the modules folder in sites/all/modules for "ubercart" to manually remove.

Overall this is a heavy lifting module deletion module that takes most of the work out of maintaining your drupal 7 system. It can delete most custom modules, and incorrectly formatted modules, which is why it was made in the first place. It can also delete most of the regular modules you use and uninstall through the uninstall window in modules. It is great at deleting junk modules so enjoy it.
