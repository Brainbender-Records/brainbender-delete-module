This drupal 7 modules does something every drupal developer wanted since the creation of Drupal 7. It deletes modules from the server without you actually having to go, login to your server and move files manually. This module might throw an error and say something "could not be deleted" but in reality it probably was deleted. You must be careful using this module as you can figure it will delete files including important ones. For power users that want a clean modules page this is a super useful module. It is like the dust buster of modules it can take all our old uninstalled modules and straight up delete them, without you taking an hour navigating through your server trying to find things. Use this module at your own risk. Since your deleting module make sure you know what your deleting or you could break your website. It is unlikely because it looks for disabled modules and uninstalled modules, but you should delete modules with care, it shows a list of all kinds of things to delete you may not want to. For power users this is a cleaning utility to make your job easier and faster so enjoy it. Note this might leave a couple files behind time to time, in the case of Ubercart I was bale to delete literally 99% of the module and the module vanished from modules, but it left like 1 or 2 files in the modules page for ubercart to manually remove, but overall this is a heavy lifting module deletion module that takes most of the work out of maintaining your drupal 7 system.
